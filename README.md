# 🛡 Fuck DPI

Один трей, одно окно. Приложение объединяет
два независимых инструмента Flowseal под общим управлением:

- **[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)** — обход блокировок (Discord, YouTube и т.д.) через `winws.exe`;
- **[tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)** — свой MTProto-прокси для Telegram.

Оба работают в фоне без собственных окон и без "своих" процессов в трее —
управляются из одного `customtkinter`-окна и одной иконки в системном трее.

> 📁 Файлы `winws.exe` и `tg-ws-proxy` не входят в репозиторий — приложение
> само скачивает их последние версии с GitHub при первом запуске (см.
> [«Как это работает»](#-как-это-работает-внутри)).

## ✨ Возможности

- **Не мешает работать** — при запуске не открывает окно, только иконку в
  трее; окно открывается по клику, когда оно действительно нужно.
- **Скачивает зависимости само** — при первом запуске подкачивает
  актуальные `winws.exe` и `tg-ws-proxy` с GitHub, показывая прогресс на
  экране-заставке, а не молча "зависая".
- **Сама следит за обновлениями** — при каждом запуске тихо проверяет,
  не вышли ли новые версии zapret / tg-ws-proxy, и предлагает кнопку
  «Обновить», если да.
- **Restart из коробки** — опциональный автоперезапуск, если `winws.exe`
  или `tg-ws-proxy` неожиданно упали (например, из-за антивируса).
- **Всё в одном окне** — стратегии обхода, игровой фильтр, свои списки
  доменов, настройки Telegram-прокси, автозапуск, логи — без единого
  ручного редактирования `.txt`/`.bat`-файлов.
- **Настоящий автозапуск** — задание в Планировщике заданий Windows с
  наивысшими правами; UAC спрашивается один раз при включении, а не при
  каждом входе в систему.
- **Восстанавливает сессию** — что было запущено до выключения/
  перезагрузки, поднимается само при следующем входе.

## 🚀 Быстрый старт

1. Скачайте `Fuck-DPI.exe` (из [Releases](../../releases) этого
   репозитория, если он опубликован, либо соберите сами — см.
   [«Сборка из исходников»](#-сборка-из-исходников)).
2. Запустите файл. При первом запуске:
   - появится маленькое окно с прогрессом — приложение качает `winws.exe`
     и `tg-ws-proxy` с GitHub (нужен интернет, обычно 10–30 секунд);
   - Windows спросит права администратора (UAC) — они нужны для драйвера
     WinDivert, на котором работает `winws.exe`; согласитесь;
   - откроется главное окно — один раз, чтобы вы настроили автозапуск.
3. Дальше приложение сворачивается в трей и работает в фоне.

> ⚠️ **Требуется Windows.** `winws.exe` использует драйвер WinDivert,
> который есть только под Windows. На Linux/macOS можно запускать проект
> из исходников для разработки GUI, но сам обход блокировок работать не
> будет.

## 🧭 Первоначальная настройка (один раз)

1. На вкладке **🛡 Zapret** выберите стратегию обхода из списка (он
   читается прямо из `.bat`-файлов апстрима — какие стратегии есть у
   Flowseal, такие и увидите) и нажмите **«Запустить»**. При необходимости
   включите игровой фильтр (Выкл / Все / TCP / UDP).
2. На вкладке **✈ TG Proxy** при желании поменяйте порт/secret/DC IP,
   нажмите **«Сохранить настройки»**, затем **«Открыть в Telegram»** —
   Telegram Desktop сам предложит подключиться к прокси.
3. На вкладке **⚙ Настройки** нажмите **«Включить автозапуск»**. Это
   создаёт задание в Планировщике заданий с триггером «при входе в
   систему» и наивысшими правами — начиная со следующего входа в Windows
   приложение будет запускаться само, **без повторных окон UAC**.
4. Закройте окно крестиком — по умолчанию оно свернётся в трей, оба
   процесса продолжат работать. Если хотите, чтобы крестик полностью
   завершал приложение — снимите галочку «Сворачивать в трей при
   закрытии окна» там же, на вкладке «Настройки».

При следующих входах в Windows приложение само поднимет ту же
стратегию Zapret и то же состояние TG WS Proxy, которые были включены —
ничего перенастраивать не нужно.

Чтобы выключить автозапуск: вкладка «Настройки» → «Выключить автозапуск».

## 🔧 Сборка из исходников

Понадобится Windows (сборка **и** запуск `winws.exe` — только под ней;
писать/запускать сам GUI можно и на Linux/macOS для разработки).

```bash
git clone <ссылка-на-этот-репозиторий>
cd zapret-tg-tray

python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/macOS, только для разработки GUI

pip install -r requirements.txt
python main.py
```

При запуске из исходников без прав администратора приложение само
предложит UAC — это нормально, права нужны для драйвера WinDivert.

### Собрать один `.exe`

```bash
pip install pyinstaller
pyinstaller build.spec
```

Рядом с готовым exe при первом запуске появятся только рабочие папки:

```
ZapretTgTray.exe
vendor/    ← скачивается автоматически
data/      ← настройки, состояние, версии
logs/      ← логи zapret.log и tgproxy.log
```

## 🗂 Структура проекта

```
zapret-tg-tray/
├── main.py                      # точка входа: сплэш → трей → окно → восстановление сессии
├── config.py                    # все пути (vendor/logs/data) в одном месте
├── requirements.txt
├── build.spec                   # PyInstaller spec (сборка одного exe)
├── app.manifest                 # requireAdministrator для собранного exe
├── assets/
│   ├── icon.ico                 # иконка окна и exe
│   └── icon.png                 # иконка трея
├── core/                        # вся логика, без зависимости от GUI
│   ├── process_manager.py       # общий "движок" запуска/остановки внешнего процесса
│   ├── zapret_manager.py        # обёртка над winws.exe: стратегии, игровой фильтр,
│   │                            #   автоперезапуск, пользовательские списки доменов
│   ├── bat_strategies.py        # парсер .bat-стратегий Flowseal (без ручного JSON)
│   ├── tgproxy_manager.py       # обёртка над tg-ws-proxy: настройки → runtime, автоперезапуск
│   ├── tgproxy_runtime.py       # сам tg-ws-proxy В ПРОЦЕССЕ приложения (поток + asyncio loop)
│   ├── tgproxy_settings.py      # настройки прокси (host/port/secret/DC IP/Fake TLS)
│   ├── tg_link.py               # сборка tg://proxy ссылки (dd/ee-префикс секрета)
│   ├── fetch_vendor.py          # скачивание vendor/ с GitHub + проверка/установка обновлений
│   ├── version_store.py         # какие версии zapret/tg-ws-proxy установлены сейчас
│   ├── restart.py               # аккуратный перезапуск приложения после обновления
│   ├── state_store.py           # сохранение/восстановление состояния между запусками
│   └── autostart.py             # UAC-повышение + автозапуск через Планировщик заданий
├── gui/                         # весь customtkinter-интерфейс
│   ├── theme.py                  # цвета, шрифты, "карточки" -- единый визуальный язык
│   ├── splash.py                  # экран-заставка на время подкачки файлов с GitHub
│   └── app_window.py             # главное окно: шапка, 4 вкладки, статусы, логи
├── vendor/                       # НЕ в репозитории -- скачивается автоматически
│   ├── zapret/                   # файлы zapret-discord-youtube
│   └── tgproxy/                  # файлы tg-ws-proxy
├── data/                         # НЕ в репозитории -- создаётся при запуске
│   ├── app_state.json            # что было запущено, стратегия, тема, геометрия окна
│   ├── versions.json             # установленные версии vendor-компонентов
│   └── tgproxy_settings.json     # host/port/secret и т.д.
└── logs/                         # НЕ в репозитории -- создаётся при запуске
    ├── zapret.log
    └── tgproxy.log
```

---

**Обновления.** `core/fetch_vendor.py` умеет:

- `get_latest_zapret_release()` — тянет `tag_name` и ссылку на zip
  последнего релиза `Flowseal/zapret-discord-youtube` через GitHub API
  (с фоллбэком на последнюю известную рабочую версию, если GitHub
  недоступен или лимит запросов исчерпан);
- `get_latest_tgproxy_sha()` — тянет sha последнего коммита ветки `main`
  `Flowseal/tg-ws-proxy` (у репозитория нет релизов, версией считается
  коммит);
- `check_for_updates()` — сравнивает эти значения с тем, что записано в
  `data/versions.json` при последней установке, ничего не скачивая;
- `perform_update()` — удаляет `vendor/zapret` и `vendor/tgproxy` и
  качает их заново.

Проверка идёт тихо при каждом запуске (можно отключить в Настройках).
Кнопка «Обновить» останавливает оба процесса, удаляет старые файлы,
качает новые и перезапускает приложение.

**Состояние переживает перезагрузку.** `data/app_state.json`
перезаписывается при **каждом** изменении (старт/стоп процесса, смена
стратегии, смена вкладки, изменение окна), а не только при штатном
выходе — потому что при выключении/перезагрузке Windows процесс может
быть завершён принудительно. Запись атомарна (временный файл + замена),
поэтому обрыв питания посреди записи не портит файл.

## 🛠 Как модифицировать / расширить

ВАЖНО: проект полностью сделан нейросетью, качество кода местами может быть второсортным

Несколько отправных точек, если хочется что-то поменять:

| Хочу... | Смотреть в |
|---|---|
| Добавить новую вкладку или виджет в окно | `gui/app_window.py` → `_build_layout()` и соседние `_build_*_tab()` методы; стили брать из `gui/theme.py` (`make_card`, `heading_font`, `ACCENT` и т.д.), чтобы не разъезжался визуальный стиль |
| Изменить, какие стратегии/файлы считаются "версией" Zapret | `core/fetch_vendor.py` (`get_latest_zapret_release`, `ZAPRET_REPO`) |
| Добавить новый параметр TG-прокси | `core/tgproxy_settings.py` (dataclass `TgProxySettings`) + форма в `gui/app_window.py` (`_build_tgproxy_tab`) |
| Изменить логику автозапуска (например, на другую ОС) | `core/autostart.py` — там же весь код работы с `schtasks` |
| Поменять, что именно сохраняется между запусками | `core/state_store.py` (dataclass `AppState`) — добавляйте новое поле с значением по умолчанию, обратная совместимость со старым `app_state.json` уже обработана (`load_state` игнорирует незнакомые ключи) |
| Добавить свою стратегию обхода | Просто положите `.bat`-файл с именем `general*.bat` в `vendor/zapret/` — он появится в выпадающем списке сам, без правок кода (см. `core/bat_strategies.py`) |
| Сменить иконку/тему трея и окна | `assets/icon.ico` (окно/exe), `assets/icon.png` (трей), цвета — `gui/theme.py` |

Общие рекомендации:

- Любой обработчик, который может быть вызван из фонового потока
  (колбэки менеджеров процессов, сетевые запросы), должен обновлять GUI
  только через `self.after(0, ...)` / `self.dispatch(...)` — Tkinter не
  потокобезопасен.
- Если пишете `except ... as e:` и хотите использовать `e` внутри
  отложенной функции (`lambda`, переданная в `.after()`/`dispatch()`),
  сохраните текст ошибки в переменную **до** конца `except`-блока —
  Python удаляет переменную исключения сразу по выходу из блока.
- `core/` не должен импортировать `gui/` — если тянет добавить импорт
  `customtkinter` в `core/*.py`, это сигнал, что логика должна остаться
  в `core/`, а виджет — в `gui/`.

## ❓ Устранение неполадок (FAQ)

**Windows просит права администратора при каждом запуске.**
Это ожидаемо для собранного `.exe` (в `app.manifest` стоит
`requireAdministrator` — иначе не установится/не заработает драйвер
WinDivert). Чтобы UAC не спрашивался при каждом входе в систему —
включите автозапуск через Планировщик заданий (вкладка «Настройки»):
задание с `/RL HIGHEST` элевируется без диалога.

**После запуска долго ничего не происходит.**
При первом запуске (и после обновления) приложение качает `winws.exe` и
`tg-ws-proxy` с GitHub — на экране должен быть виден прогресс-сплэш. Если
интернет медленный или GitHub недоступен из вашей сети — подождите или
проверьте подключение.

**Стратегия не запускается / ошибка про "нераспознанные переменные".**
Скорее всего, Flowseal обновил формат `.bat`-файлов и добавил новую
`%ПЕРЕМЕННУЮ%`, которую `core/bat_strategies.py` ещё не умеет
подставлять — сообщите в issue или добавьте подстановку самостоятельно
рядом с `%GameFilterTCP%` / `%GameFilterUDP%`.

**Хочу видеть подробный лог, а не только последние строки.**
Вкладка «Логи» → «Открыть папку с логами» откроет `logs/` в проводнике —
там полные `zapret.log` и `tgproxy.log`.

**Как полностью сбросить настройки?**
Закройте приложение и удалите папку `data/` рядом с exe — при следующем
запуске всё создастся заново со значениями по умолчанию.
